# EstiMate — Philippine House Price Prediction

## Run the application

Install the dependencies and start the Flask server from the project directory:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

Open `http://127.0.0.1:5000` in a browser. The app loads
`models/house_price_xgboost.pkl` once when Flask starts; keep that file in the
`models/` directory.

The **Calculate Value** button sends the selected bedrooms, bathrooms, floor
area, and land area to `POST /predict`. The endpoint accepts JSON fields named
`Bedrooms`, `Bath`, `Floor_area (sqm)`, and `Land_area (sqm)`. To match the
current UI controls, accepted ranges are 1–5 bedrooms, 1–4 baths, 20–1,000 sqm
floor area, and 20–30,000 sqm land area. The API responds with a numeric
`prediction` in PHP. Other dashboard metrics remain the existing static UI
content and are not generated by this model.
